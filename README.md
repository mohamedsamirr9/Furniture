# 🪑 Furniture E-Commerce Platform


A scalable full-stack furniture e-commerce platform built with **ASP.NET Core Web API** and **Angular**, supporting multiple user roles and custom product workflows.

## 📌 Overview

This project is part of my Full Stack .NET training at ITI, focusing on building a real-world e-commerce system with clean architecture and scalable design.

The platform supports:
- Admin
- Seller
- Customer

With advanced features like custom furniture requests and offer negotiation.

---

## 🛠️ Tech Stack

### 🔹 Backend
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- JWT Authentication
- LINQ

### 🔹 Frontend
- Angular
- TypeScript
- HTML5 / CSS3
- Bootstrap

### 🔹 Architecture & Patterns
- Onion Architecture
- Unit of Work Pattern
- Repository Pattern
- DTOs & Services Layer

## 🚀 Features


#### 👤 Authentication & Authorization
- JWT-based authentication
- Role-based access (Admin, Seller, Customer)

#### 🛍️ Products Management
- Create, update, delete products
- Categorization
- Product listing & details

#### 🧑‍🎨 Custom Requests
- Customers can request custom furniture
- Sellers can submit offers
- Offer negotiation workflow
  
#### 🛒 Cart & Orders
- Add to cart
- Checkout system
- Order management

#### 🧾 Admin Panel
- Manage users, products, and complaints
- Monitor platform activity

#### 🏪 Seller Panel
- Seller dashboard
- Manage products & offers & orders
